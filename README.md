# YouTube

Link a YouTube account to your workspace so agents can read channel uploads through the YouTube Data API. The connection reuses your existing Google sign-in, so there is nothing extra to configure on the Google side once Sign in with Google is already set up.

## Capabilities

- Connect a YouTube account to your workspace
- Let agents list a channel's uploads through the YouTube Data API
- Feed channel uploads into transcript, summary, and media-research workflows
- Disconnect the account when access should be revoked
